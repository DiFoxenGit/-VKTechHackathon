# Регрессионный прогон вёрстки

Каждый фикс вёрстки проверяется на одном и том же входе: фиксированный план колоды
и одни и те же шаблоны. Модель не вызывается, поэтому любая разница в отчёте
объясняется изменением кода или шаблона, а не случайностью генерации.

## Что прогоняется

**План** — [`tools/regress_outline.json`](../tools/regress_outline.json), 12 слайдов по
материалу [`samples/source/материал-инициатива.md`](../samples/source/материал-инициатива.md).
Все ссылки на источник — `"brief"`, числа аудит сверяет с этим материалом.

| № | Слайд | Визуализация | Что проверяет |
|---|---|---|---|
| 1 | Обложка | none | титульная страница шаблона, одна строка под заголовком |
| 2 | Ручная сборка 186 минут | none | обычный список из трёх тезисов |
| 3 | 4 минуты вместо 186 | **bar**: 2 категории, 1 ряд, единица | сильный разброс значений: короткий столбец не должен пропасть |
| 4 | Пять шагов | **process**, 5 шагов | подписи в шевронах на узкой колонке |
| 5 | Дизайн-система | **icon**, 5 шагов | пиктограммы и подписи |
| 6 | Пилот | **table** 3 колонки × 3 строки | нативная таблица |
| 7 | Было и стало | **comparison** 2 × 3 | две колонки сравнения |
| 8–10 | Результаты, стоимость, риски | none | число с разрядами «1 400», плотные списки |
| 11 | План | **timeline**, 3 шага | даты на временной шкале |
| 12 | Запрос решения | none | финальная страница |

**Шаблоны.** В репозиторий не коммитятся: это файлы организаторов. На машинах команды
они лежат рядом с проектом:

| Путь | Что |
|---|---|
| `../backend-audit/Датасет/` | три шаблона кейса: VK Tech, VK WorkSpace, VK Education |
| `../backend-audit/Презентация/ЛЦТ2026 Шаблон презентации.pptx` | «незнакомый» шаблон, на нём вёрстку не настраивали |

## Как запустить

```bash
python tools/bench_templates.py ../backend-audit/Датасет \
    "../backend-audit/Презентация/ЛЦТ2026 Шаблон презентации.pptx" \
    --outline tools/regress_outline.json \
    --source samples/source/материал-инициатива.md \
    --render out/ --sheets out/ --json out/regress.json --markdown out/regress.md
```

| Флаг | Что делает |
|---|---|
| `paths…` | папки с `.pptx` и/или отдельные файлы, можно несколько |
| `--outline` | план колоды; по умолчанию короткий `tools/bench_outline.json` на 6 слайдов |
| `--source` | материал, с которым аудит сверяет числа; по умолчанию — текст самого плана |
| `--render DIR` | pptx, pdf и PNG каждого слайда; нужен LibreOffice |
| `--sheets DIR` | контакт-лист 3×N на колоду (`<шаблон>_<вариант>_sheet.png`); без `--render` слайды рендерятся в ту же папку |
| `--variants` | какие варианты вёрстки собирать, по умолчанию `classic,split,focus` |
| `--json`, `--markdown` | отчёт целиком и таблица в Markdown |

Без `--render` LibreOffice не нужен: колоды всё равно экспортируются во временную папку,
потому что метрики снимаются с записанного файла. Четыре шаблона × три варианта без
рендера — около 15 секунд.

Код выхода — 1, если какой-то шаблон не разобрался или у колоды есть **ошибки** аудита.
Предупреждения прогон не роняют: они видны в отчёте.

## Колонки отчёта

Всё, кроме находок аудита, считается по реально записанному PPTX: что попало в файл,
то и увидит зритель.

| Колонка | Как считается |
|---|---|
| ошиб, предупр | находки детерминированного аудита по колоде |
| карт | сколько слайдов разложены по карточной сетке шаблона |
| мин.кегль | наименьший явно заданный кегль у текста на слайдах и в диаграммах; в JSON рядом — где именно (`min_font_where`) |
| шрифты | гарнитуры из `a:latin typeface` в XML слайдов |
| диагр | число нативных диаграмм |
| без легенды | диаграммы без `c:legend` |
| без осей | диаграммы, у которых ни одна ось не подписана (`c:title` у оси) |
| без значений | диаграммы без подписей значений (`c:dLbls/c:showVal = 1`) |
| высота диагр | доля высоты слайда под каждой диаграммой (высота рамки / высота слайда) |

Фрагменты текста без явного кегля (например, колонтитулы шаблона, которые наследуют
размер от мастера) в минимум не входят: без полного разбора цепочки стилей его честно
не посчитать. Их число — в JSON, поле `implicit_size_runs`.

## В CI

Джоба **Tests / Integration (regress, LibreOffice)** в
[`tests.yml`](../.github/workflows/tests.yml) делает тот же прогон в боевом образе
бэкенда: те же LibreOffice и шрифты, что на сервере. Шаблонов кейса в CI нет, поэтому
[`tools/make_fixture_templates.py`](../tools/make_fixture_templates.py) собирает два
синтетических:

- **«Светлый 16x9»** — логотип на каждой странице, оглавление, три карточки в ряд, раздел, «Спасибо»;
- **«Тёмный 4x3»** — другая пропорция, тёмный фон, светлый текст, сетка 2×2.

Таблица попадает в сводку прогона (Summary), контакт-листы и `regress.json` — в
артефакт **regress-sheets**, он хранится 14 дней. Деплой ждёт, пока зелёными станут все
три джобы этапа Tests.

## Первый прогон, 19 сентября 2026

Четыре шаблона × три варианта, 12 слайдов: **ошибок аудита 0** ни в одной колоде.
Новые колонки сразу показали, что стоит чинить:

| Находка | Где | Причина |
|---|---|---|
| кегль 6 pt | слайд 4 в варианте `split` у всех шаблонов, у VK Tech — во всех трёх вариантах | подписи в шевронах схемы «процесс»: на узкой колонке `label()` в `exporting.py` упирается в нижнюю границу 6 pt |
| нет подписей значений | все 12 колод | у столбца «4» рядом со «186» значение не видно, прочитать его можно только по сетке |
| нет легенды | все 12 колод | так задумано для одного ряда (легенда повторяла бы подпись); колонка нужна, чтобы заметить регресс, когда рядов станет больше |
| 12 × `text_over_image`, 3–4 × `margin_encroachment` | ЛЦТ2026 | фотофоны на большинстве страниц, блоки заходят в поля |

Контакт-листы ЛЦТ2026 (вариант `split`) показывают то, чего нет в цифрах:

- **слайд 4** — шевроны процесса сжаты в правый нижний угол, половина слайда пустая;
- **слайды 2, 9, 12** — текст лежит поверх пустых рамок-карточек шаблона: сетка не распознана, а рамки перенесены;
- **слайд 11** — подписи таймлайна мелкие и разнесены по разные стороны линии;
- **слайд 3** — столбец «4» — полоска у оси, значения не подписаны;
- **слайд 5** — «Гарнитуры» переносится по слогам в подписи иконки;
- цветная плашка заголовка шаблона остаётся пустой, заголовок стоит под ней.
