# Стёпа: периоды и условия в API/UI

19 октября 2026. Ветка `codex/stepa-periods-ui` основана на `feat/dima-periods-context`, коммит `0676b24` (PR #67), который уже содержит объединённую проверку Андрея. Из архива «Проверка-Андрея.zip» использованы отчёт и визуальные результаты как исходные свидетельства; описанные там будущие действия не считаются результатами этой итерации.

## Поведение приложения

После загрузки материалов доступен переключатель «Задать периоды и условия бизнес-анализа». Он открывает пять диапазонов закрытых месяцев: отчёт, сравнение, год назад, история и план. Исходные значения явно подписаны как сценарий III квартала 2026. Даты компьютера и максимальные даты таблицы не выбирают период за пользователя.

Периоды можно изменить в форме или загрузить из `settings.json`. В разделе условий можно загрузить `conditions.json` либо заполнить значения и цитаты вручную. Отдельно выбирается загруженный файл контекста. В форме редактируются бюджет, резерв, ресурсы, владельцы, отчётный диапазон, событие канала и восемь смысловых разделов. Технический JSON не показывается в обычном интерфейсе. Импорт параметров не добавляет JSON как ещё одну таблицу продаж.

«Проверить данные» пересчитывает весь комплект источников. После изменения параметров старый предпросмотр анализа убирается. Для новой колоды одной операцией пересчитываются аналитика, история, ограничения и календарные сроки. Существующая презентация остаётся в проектах; в редакторе есть переход «Пересчитать из источников» к её сохранённому брифу. Пересоздание не переносит неподтверждённые ручные формулировки старой истории.

Названия, пояснения расчёта, подписи источников и сроки используют выбранные периоды. Для кварталов в заголовках используются короткие подписи вроде «II кв. 2026», для иных диапазонов — конкретные месяцы. Старые машинные идентификаторы метрик не определяют отображаемый период. «Как посчитано» связывается с соответствующим бизнес-слайдом в редакторе.

## API и сохранение

Поля доступны в `POST /api/v1/analysis`, `/outlines` и `/generations`:

```python
import json
from pathlib import Path

folder = Path("samples/business-acceptance/period-context-v1")
payload = {
    "brief": "Чистая выручка, прибыль, маржа и план-факт",
    "template_id": template_id,
    "slide_count": 12,
    "content_pack_ids": [sales_id, plan_id, products_id, regions_id, context_id],
    "business_settings": json.loads((folder / "settings.json").read_text(encoding="utf8")),
    "business_conditions": json.loads((folder / "baseline/conditions.json").read_text(encoding="utf8")),
    "business_context_id": context_id,
}
# ID возвращаются при загрузке исходных файлов и шаблона.
# Отправьте payload в POST /api/v1/analysis или /api/v1/generations.
```

В примере `current` — апрель–июнь 2026, `previous` — январь–март 2026, `year_ago` — апрель–июнь 2025; история — январь 2025–июнь 2026, план — весь 2026 год. Для `/outlines` поле `template_id` не передаётся. Строгая схема запроса не допускает произвольные поля.

Периоды и условия сохраняются в `sources[0].business_request` отдельно от вычисленного `sources[0]._business`. Этот сохранённый вход передаётся явно в `build_business_analysis(settings=...)` и `build_business_story(conditions=...)` при каждом воспроизведении. Защита повторно рассчитывает оба результата и сверяет представления и слайды с ними. Настройки из редактируемого результата не заменяют сохранённый запрос.

Публичная запись презентации возвращает `business_request` с ключами `settings`, `conditions`, `context_source_id`. Браузер хранит эти же параметры в `brief.business` у черновика и каждой презентации. Сохранение названия, оформления и порядка слайдов сохраняет запрос и создаёт новую ревизию. PATCH редактора не принимает новые доверенные параметры; для их изменения используется повторная генерация из источников.

Без новых полей исходный согласованный сценарий остаётся доступен с прежним контекстом. Выбор другого периода требует подходящего контекста и условий. При воспроизведении старой защищённой записи `business-service-1` возвращается объяснение: пересоздать колоду из исходников. Новые записи имеют версию адаптера `business-service-2`.

## Отказы и границы

Неполные/несопоставимые периоды, неверные цитаты, неподтверждённые значения, неверный файл контекста и дублирование таблиц останавливают расчёт. Ошибки периодов и привязки условий поясняются по-русски. Условия и выбранный файл передаются вместе; ID должен входить в выбранные материалы. Никакой автоматической смысловой интерпретации произвольного текста это не добавляет.

История заканчивается отчётным месяцем. В Q2-наборе все 1512 строк продаж сохраняются, 216 строк вне истории перечислены в `source_scope` и исключены из графиков/сумм. Это явно показано в предупреждениях и пояснениях. Скачивание исходника возвращает исходные байты.

Цитата доказывает присутствие указанного фрагмента в текущем тексте, но не разрешает противоречия между прочими частями документа. Нормализованные условия требуют содержательной проверки автора/Андрея. Статус мощности отражает ограничения, а не обещание количества запусков.

## Воспроизведение

```powershell
$env:PYTHONPATH=(Resolve-Path backend).Path
# При необходимости задайте DESIGNER_SOFFICE абсолютным путём к LibreOffice.
.\.venv\Scripts\python.exe -m pytest backend/tests -q
Set-Location frontend
npm run check
npm run build
Set-Location ..
.\.venv\Scripts\python.exe tools/check_periods_service.py --url http://127.0.0.1:8026/api/v1
```

HTTP-прогон предполагает запущенный backend с тремя оригинальными корпоративными шаблонами. Он проверяет Q2 на всех трёх шаблонах × трёх оформлениях и версию B на VK Tech × трёх оформлениях, сверяет нативные числа диаграмм, 12 страниц PDF/PPTX, preview ревизии 2, сохранение запроса и отказ при подмене вывода. Артефакты: `output/periods-service/`; они игнорируются Git.

Новые проверки сервиса находятся в `backend/tests/test_business_period_service.py`, проверки передачи и хранения параметров — в `frontend/scripts/check-business.mjs` и входят в `npm run check`.

## Результаты локальной проверки

- Профильный backend-набор: **43 passed**, включая новый сервисный контракт, старый сценарий, защиту изменений, сохранение/повторное открытие и границы конвейера. Отдельная проверка знака и геометрии отрицательных столбцов с LibreOffice: **1 passed** после финального исправления подписей.
- `npm run check` и `npm run build` проходят в монорепозитории и отдельном frontend-репозитории. Проверяются передача условий в анализ/генерацию, хранение в черновике и презентации, сохранение незавершённого ввода месяца при перезагрузке и привязка пояснений к бизнес-слайдам.
- Через браузер при 1440×900: загрузка источников, импорт параметров, общий анализ, генерация, запрет правки проверенного вывода, изменение названия, сохранение, смена оформления, скачивание PPTX/PDF, повторное открытие. Сохранены Q2-параметры, оформление и ревизия. Неподтверждённое изменение инженеров 2→3 даёт понятный отказ без старого анализа на экране.
- Через браузер при 1920×1080: замена продаж и контекста на B, импорт новых условий, проверка и новая колода. KPI обновился до **94 823 698 ₽**; прежняя колода осталась в проектах.
- Независимые контрольные значения Q2: net **93 563 698 ₽**, прибыль **30 580 684 ₽**. B: net **94 823 698 ₽**, прибыль **31 570 684 ₽**. Дельты: **+1 260 000 ₽** и **+990 000 ₽**. В обоих случаях исключены 216 строк вне истории, последний месяц линии — июнь 2026.
- Визуально исправлены выход полей месяцев за границы карточек и пересечение названия региона со значением отрицательного столбца. Отрицательные подписи размещаются внутри столбцов с контрастным цветом; формат и видимость явно записываются для каждой точки, поскольку LibreOffice не наследует их при локальных переопределениях. Маленькие отрицательные столбцы сохраняют числовую шкалу без тесной подписи. Числа в книге диаграммы не меняются. Финальная страница WorkSpace проверена рядом с декором.
- Аудит не отключён: в вариантах остаются предупреждения о плотности текста, шкале шрифта и оформлении. Отсутствие критической ошибки не подменяет визуальное утверждение Андрея. Живое изображение в этом прогоне не запрашивалось.

Артефакты: `output/periods-service/service-report.json`, `baseline/`, `version-b/` (PPTX, PDF, страницы PNG, контактные листы), `ui-controls-1440.png`, `ui-refusal-1440.png`, `ui-reopened-1440.png`, `ui-controls-b-1920.png`, `ui-version-b-1920.png`, `ui-saved.pptx/pdf`.
