### P0-3. Пересборка девяти эталонных колод

**Почему сейчас.** Набор в `samples/` собран 21 сентября в 12:38, а большая работа по
визуальным ассетам (иконки из шаблона, иллюстрации, фактоиды, замена значков-образцов)
влилась позже, в 15:43. То есть жюри промежуточного этапа увидит колоды **до** главного
улучшения качества. Плюс с тех пор закрыты проверки файла и подписи диаграмм.

**Что именно требует ТЗ.** «Результат демонстрации сервиса — три варианта презентации,
сгенерированные на одном контенте на трёх разных шаблонах (всего 9 вариантов презентаций)».
Контент обязан быть один и тот же, шаблоны — три разных, варианты — три.

**Как собирается.**

```bash
python tools/make_samples.py http://158.160.225.35
```

Скрипт загружает `samples/source/материал-инициатива.md` как контент-пакет, берёт три
шаблона из `templates/` на сервере, запускает одну задачу на шаблон (в каждой сервис верстает
сразу три варианта), дожидается её и складывает в `samples/` девять `.pptx`, девять `.pdf` и
`report.json` с числами: слайды, время, ошибки и предупреждения аудита по каждой колоде.

**После сборки нужно:**

1. обновить таблицу в `samples/README.md` числами из свежего `report.json`;
2. дописать в `samples/README.md` дату и коммит, на котором собрано;
3. открыть глазами хотя бы по одной колоде каждого шаблона: обложка, слайд с диаграммой,
   слайд с иконками, финал;
4. одним PR влить `samples/*` и обновлённый README.

**Готово, когда:**

- девять колод лежат в `samples/`, все собраны на одном и том же коммите master;
- в каждой 10–15 слайдов (целевой объём ТЗ) и **ноль ошибок аудита** в `report.json`;
- время каждой задачи меньше 5 минут;
- в колодах видно то, ради чего делались визуальные ассеты: иконки по смыслу, иллюстрации,
  фактоиды с крупными числами;
- `samples/README.md` описывает набор и объясняет предупреждения.
