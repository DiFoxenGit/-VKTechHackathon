# Z-Image Turbo через GenAPI

Транспорт изображений подключается отдельно от текстовой модели. Выбранный профиль `genapi` вызывает только `https://api.gen-api.ru/api/v1/networks/z-image` с режимом `turbo` и 8 шагами. Это Z-Image Turbo с открытыми весами под Apache 2.0 (6B); в оригинальном ТЗ пункт 3.1 ограничивает text-to-image до 20B, а общий раздел моделей — до 35B.

## Настройка backend

В закрытом серверном `.env`:

```dotenv
DESIGNER_IMAGE_PROVIDER=genapi
DESIGNER_IMAGE_MODEL=z-image
DESIGNER_IMAGE_API_KEY=<отдельный ключ GenAPI>
DESIGNER_IMAGE_SIZE=1024x1024
DESIGNER_IMAGE_LIMIT=6
```

`DESIGNER_IMAGE_BASE_URL` для профиля GenAPI не используется: адрес официального API зафиксирован адаптером. Ключ текстовой модели не подставляется вместо image-ключа. Docker Compose передаёт image-настройки в backend; Compose auto-sell уже использует `env_file`.

Профиль `openai` остаётся совместим с прежним `/images/generations`. Новых библиотек не требуется.

## Выполнение и ограничения

1. Создаётся одна задача: `POST /networks/z-image`. Повторы POST отключены, чтобы не создавать лишние платные генерации. Необязательное поле `callback_url` отсутствует: реальный API отклоняет явный `null` с HTTP 422. Минимальная сторона — 512 пикселей.
2. Результат опрашивается через `GET /request/get/{id}` раз в 2 секунды; общий предел — 150 секунд.
3. При успехе PNG скачивается без заголовка авторизации. Разрешены только HTTPS-адреса GenAPI и документированного хранилища `gen-api.storage.yandexcloud.net`; редиректы не выполняются. Максимум файла — 20 МиБ.
4. Существующая библиотека ассетов сохраняет картинку один раз и использует её в вариантах колоды. Ошибка image-провайдера обрабатывается существующим запасным сценарием без картинки.

При таймауте задача у провайдера может продолжать выполняться; автоматическая повторная отправка не производится. Следующий запуск пользователем может создать новую платную задачу.

Используются `guidance_scale=0`, PNG, одна картинка на вызов; платные перевод и расширение промпта выключены. Для воспроизводимой стилизации предпочтителен английский промпт. Числа, графики и текст слайдов создаёт сервис; image-модель предназначена для иллюстраций.

Сквозная проверка 20 октября подтвердила две фотографии в трёх оформлениях, точные слайды и стороны размещения, сохранение картинок в PPTX/PDF. План выбирает текстовая модель; графики и таблицы защищены от замены иллюстрациями. Контракт плана и ограничения — в [model-image-plan.md](model-image-plan.md), примеры транспорта и итог D1–D4 — в [dima-provider-demo-readiness-2026-10-20.md](dima-provider-demo-readiness-2026-10-20.md). Проверка короткого сценария не заменяет приёмку полной бизнес-презентации.

## Безопасность и проверки

Ключ остаётся только на backend, в игнорируемом `.env` с правами 600. Тела ошибок провайдера, ключи и заголовки не включаются в диагностику. Тесты `backend/tests/test_genapi_images.py` проверяют формат Turbo, единственную отправку, опрос, ошибки, таймаут, лимит загрузки, недоверенные URL и отсутствие ключа при скачивании.

Документация: [модель](https://gen-api.ru/model/z-image/api), [создание задачи](https://gen-api.ru/docs/v1/generations/ai-request), [результат](https://gen-api.ru/docs/v1/generations/getting-the-result).
