## Что изменилось

Бизнес-история сохраняет 12 проверенных страниц. Один запрос существующего
`designer.ai.ask` редактирует заголовки и разрешённые текстовые блоки, после чего
один проверенный ответ используется для трёх оформлений. В prompt передаются
периоды, определения метрик, факты с ID, действия и релевантный контекст.
Полные строки продаж в каждый запрос не копируются. Числа, даты, серии,
таблицы и доказательства остаются под управлением расчётного слоя.

Редактура проходит строгую схему, проверку ссылок и привязку к текущему входу.
При сохранении, повторном открытии и экспорте она проверяется заново. Ответ
от другой версии исходников/условий не подходит. Проверка свободного языка
остаётся ограниченной: механическая проверка схемы и фактов не заменяет
содержательную оценку формулировок реальной Qwen.

В задании и каждой сохранённой колоде есть `inference`: запрос, фактические
попытки HTTP, модель, длительности, результат проверки, резервный текст,
response ID и usage при наличии. `generation.mode=llm` требует фактического
успешного проверенного ответа. Настроенный ключ таким доказательством не является.
Вспомогательные операции учитываются отдельно от основного текста.

При отказе Qwen сохраняется расчётная колода с явным предупреждением.
«Повторить с моделью» создаёт новую презентацию и сохраняет прежнюю. В обычном
интерфейсе нет response ID и технического JSON; сведения о модели доступны
в раскрываемой диагностике. Карточки файлов показывают объём, роль и статус;
периоды и пустые цитаты получают пояснения рядом с полями.

Выбор шаблонной страницы учитывает количество и вместимость блоков. Риски
распределяются по карточкам; длинные действия получают подходящую свободную
компоновку. Убраны пустые контейнеры, исправлены подписи и геометрия отрицательных
столбцов, показаны все регионы, источники отделены от строк таблиц.
Для текстовых страниц исправлено исчезновение фирменного подвала LibreOffice.
Графики и таблицы остаются нативными. PDFium защищён общим lock: параллельные
маршруты не обращаются одновременно к его состоянию внутри процесса.

## Запуск

Установить `backend/requirements.txt` и `pytest`, выполнить `npm ci` в `frontend`.
Для PDF нужен LibreOffice; оригинальные три VK-шаблона разместить в `templates/`.
Закрытое окружение приложения заполнить по `.env.example`: профиль VK, адрес,
модель, ключ и Project ID. При Docker использовать `docker compose --env-file
.env.local up --build`; профиль VK и независимые параметры image-провайдера
передаются в backend. Секреты не использовать в переменных `VITE_*`.

Для ручного запуска backend: `uvicorn designer.app:create_app --factory` с
`PYTHONPATH=backend` и уже загруженным закрытым окружением. Локальный QA API был
`http://127.0.0.1:8036/api/v1`, frontend — `http://127.0.0.1:5186`.
