## Что доделано

- P1-5: запоздалая ошибка предыдущего запроса не очищает новое превью;

- P1-6: показ времени ожидания и отсутствия автоматического исправления,
  защита модельных находок от кнопки автоисправления. Кнопки переносят длинный текст.
  Сервер сохраняет результаты другого режима в той же ревизии; повтор заменяет
  только свои находки. Два флага запускают обе проверки; правка слайда сбрасывает
  устаревшие находки. Слияние под блокировкой учитывает актуальный сохранённый отчёт.
- P1-7: обоснование, таблица, ссылки на функции, примеры страниц эталонов.
- P1-8: обновлён gap-analysis, создан `docs/plan-to-win.md`, убраны устаревшие
  утверждения об HTML и одинаковой плотности вариантов. Исторические замеры
  отделены от новой проверки. P3-16 не выдана за выполненный живой переход.
- При проверке обнаружен дефект библиотеки: список API возвращает краткие записи
  без deck, но клиент пытался преобразовать их как полные презентации и скрывал
  ошибку. Теперь загружаются полные записи, ошибка показывается, подпись корректно
  говорит о серверном хранении. Открытие сохранённой колоды проверено в браузере.

Модельные ответы локального стенда контролируемые; PDF для проверки рамок —
локальная фикстура. Это проверка интерфейса, API и состояния, не новый замер
качества модели или экспорта LibreOffice. Живые прогоны P1-4/5/6 от 22 сентября
описаны в соответствующих журналах. Стенд `158.160.225.35` при повторной проверке
не ответил (ERR_CONNECTION_TIMED_OUT). P1 реализована; повторная приёмка
развёрнутой версии зависит от доступности стенда. Инференс VK по-прежнему
требует предоставленного доступа и отдельного полного прогона.
