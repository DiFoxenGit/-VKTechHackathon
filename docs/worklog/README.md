# Журнал работ

Здесь записывается каждая законченная работа: фикс бага, новая проверка, изменение CI.
Один файл на задачу — так параллельные PR не конфликтуют в одном файле.

Имя файла: `ГГГГ-ММ-ДД-коротко-о-задаче.md`. Внутри — по шаблону:

```markdown
# Что сделано (одна строка)

**PR:** ссылка · **Автор:** кто · **Дата:** ГГГГ-ММ-ДД

## Проблема
Что было не так и как это проявлялось. Для бага — шаги воспроизведения.

## Причина
Корень, а не симптом: файл, функция, условие.

## Что изменено
Файлы и суть правки.

## Тесты
Какие тесты добавлены или обновлены и что именно они проверяют.
Как проверить руками: команда регресса и что смотреть в контакт-листах.

## Результат
Цифры до и после: отчёт регресса, число находок аудита, время.
```

Проверка вёрстки для раздела «Результат» — регрессионный прогон, см. [regression.md](../regression.md).
