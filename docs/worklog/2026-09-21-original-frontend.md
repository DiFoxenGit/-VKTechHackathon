# Интерфейс команды вернулся и работает на настоящем сервисе

**PR:** [#19](https://github.com/DiFoxenGit/-VKTechHackathon/pull/19), [#20](https://github.com/DiFoxenGit/-VKTechHackathon/pull/20) · **Автор:** DiFoxen + Claude · **Дата:** 2026-09-21

## Задача

Вернуть фронтенд, с которого начинался проект (первый коммит, прототип H10ms), и сделать
так, чтобы в нём работало всё — то есть через реальный бэкенд, а не через браузерный
демо-движок.

## Что сделано

Восстановлены экраны прототипа: главная с композером брифа, структура, «Одна история. Три
взгляда», редактор со списком слайдов, галерея шаблонов, «Мои презентации», модалки помощи,
настроек, экспорта и предпросмотра.

Вся работа переведена на API. `services/presentationService.ts` из заглушки стал настоящим
адаптером — это единственное место, где экраны встречаются с сервисом:

| Экран | Что делает сервер |
|---|---|
| Композер | материалы уходят контент-пакетами: TXT, MD, CSV, JSON, PDF, DOCX, PPTX разбирает бэкенд |
| Генерация | бриф → структура → три свёрстанных варианта; прогресс и стадии видны строкой |
| Три взгляда | варианты уже собраны, переключение не перегенерирует колоду |
| Редактор | правка слайда уходит `PATCH`, сервер пересобирает слайд и пересчитывает аудит |
| Проверка слайдов | находки с сервера; у исправимых — кнопка «Исправить», она создаёт новую ревизию |
| Просмотр | SVG страницы, отрисованной сервисом: на экране то же, что уедет в файл |
| Скачать | настоящие PPTX, PDF и HTML с бэкенда |
| Шаблоны | список и дизайн-система с сервера, загруженный PPTX разбирает бэкенд |
| Мои презентации | история с сервера, открытие подтягивает текущую ревизию |

Браузерный движок генерации, аудита и экспорта удалён: от `engine.ts` осталось 56 строк —
пример брифа и расчёт кегля для миниатюр. Ушли и надписи про демо-режим: теперь всё
настоящее. Предупреждения задачи (например, «модель собрала 8 слайдов вместо 10») выводятся
отдельной плашкой.

## Баг, найденный проверкой на стенде

После первого деплоя страница открывалась белой: `TypeError: Cannot read properties of
undefined (reading 'name')`. Прототип брал запасной шаблон из статического массива, а
теперь список приходит с сервера и на первом рендере пуст. Добавлен шаблон-заглушка с теми
же полями — живёт до ответа сервера, виден как «Загружаем шаблоны…» ([#20](https://github.com/DiFoxenGit/-VKTechHackathon/pull/20)).

## Проверка

Типы и сборка — в CI. Полный путь пройден руками на стенде:

1. бриф → «Создать презентацию» → прогресс по стадиям;
2. экран трёх вариантов: 10 слайдов, шаблон VK Education;
3. редактор: настоящие заголовки и тезисы, список слайдов, миниатюры;
4. «Просмотр» — страница, отрисованная сервисом;
5. «Проверка слайдов» — 13 находок с сервера, нажатие «Исправить» на одной оставило 12.

Экспорт проверен на уровне API тем же прогоном, что собирает `samples/`.

## Что осталось

- Тёмной темы в прототипе не было; переключатель тем из прошлой версии интерфейса не
  возвращал. Если он нужен, это отдельная задача: у прототипа своя палитра.
- Экран «Структура» пока показывает слайды и порядок, но правка структуры до вёрстки в него
  не заведена — в прототипе её не было, а сервис такое умеет (`POST /outlines`).
