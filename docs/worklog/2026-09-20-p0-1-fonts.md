# P0-1: кириллица и ссылки на гарнитуры темы

**PR:** [#12](https://github.com/DiFoxenGit/-VKTechHackathon/pull/12) · **Автор:** Codex · **Дата:** 2026-09-20

## Проблема и причина

ЛЦТ2026 экспортировался с Poppins Light. Ссылки `+mn-lt`/`+mj-lt`
отбрасывались, а отдельный латинский образец мог определять шрифт всей колоды.
Стандартный аудит считал такую гарнитуру допустимой, поскольку она есть в шаблоне.

## Что изменено

- `parsing.py`: разрешение ссылок темы, включая `cs`, с учётом темы конкретного
  мастера; частота по числу символов отдельно для заголовков и основного текста.
  `PARSER_VERSION` увеличена до 17 для переразбора сохранённых шаблонов.
- `fonts.py`: cmap встроенного sfnt/EOT или системного шрифта через fontTools;
  при недоступности файла — ограниченный список известных гарнитур. Неизвестное
  покрытие не выдаётся за доказанное отсутствие символов.
- `tokens.font_choice` содержит выбранную гарнитуру, кандидатов, вес и причину;
  `tokens.font_coverage` сохраняет источник сведений и диапазоны символов.
- `layout.py`: заголовки и основной текст получают свои выбранные гарнитуры.
- `audit.py`: `font_missing_glyphs` (error) для текста и подписей визуализаций.
  `AUDIT.md` дополнен. Исправления P1-4 команды сохранены без замены.

## Тесты

`PYTHONPATH=backend python -m pytest backend/tests/test_fonts.py -q`: **4 passed**.
Проверяются ссылки на тему, вес по символам, замена Poppins на Calibri в
синтетическом русском шаблоне, встроенный cmap, настоящий XML экспортированного
PPTX и срабатывание аудита после намеренной подмены гарнитуры.

Прогон в Linux-образе бэкенда с LibreOffice:

```bash
python tools/bench_templates.py /templates --outline tools/regress_outline.json \
  --source samples/source/материал-инициатива.md \
  --render tmp/fonts-render --sheets tmp/fonts-sheets \
  --json tmp/fonts.json --markdown tmp/fonts.md
```

## Результат

Четыре реальных шаблона × три варианта × 12 слайдов: **0 ошибок**, 95
предупреждений; минимальный явно записанный кегль 11 pt во всех колодах.
На ЛЦТ в XML вместо Poppins Light записан **Montserrat** — это гарнитура
активного мастера `theme1.xml`. Calibri из `theme2.xml`/`theme3.xml` не должна
подменять тему активного мастера. В синтетическом шаблоне с темой Calibri
выбирается Calibri, как требуется планом.

Контакт-лист ЛЦТ classic проверен визуально: кириллица читается без разрядки.
Оставшиеся пустые плашки и пересечения карточек относятся к P0-2/P0-3 и данным
PR не исправляются. Шаблоны и рендеры организаторов не включены в Git.
