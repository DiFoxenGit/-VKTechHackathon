# P2-1. Целевой объём колоды, число тестов, адрес стенда и ссылки на модели

**PR:** fix/p2-1-slide-count · **Автор:** DiFoxen + Claude · **Дата:** 2026-09-20

## Проблема

ТЗ: «Целевой объём 10–15 слайдов (или заданный пользователем)». В `samples/` лежали колоды
на 7 слайдов при запрошенных 10, и пользователь об этом нигде не узнавал.

Плюс три расхождения в документации: бейдж «58 сценариев» против «69 сценариев» в тексте
README при фактически другом числе; `docs/test-run.md` не объяснял, что делать, если
стенд недоступен; в `MODELS.md` не было ссылок на Hugging Face для используемых моделей,
хотя ТЗ требует показать веса и лицензию.

## Причина

`generate_outline` в `generation.py` принимал любой недобор до 60 % запрошенного объёма
**с первой попытки**: условие `floor <= count <= slide_count` пропускало 7 слайдов из 10,
и модель никогда не получала шанс исправиться. Перебор при этом отклонялся.

## Что изменено

`backend/designer/generation.py`:

- недобор возвращается модели с конкретной просьбой: разбить самые насыщенные слайды по
  смыслу или добавить слайды с таблицей либо схемой по материалам;
- меньшее число слайдов принимается только на последней попытке, и тогда в задачу
  добавляется предупреждение с числами: сколько собрано, сколько просили и что делать;
- перебор не проходит никогда: на последней попытке лишние слайды отсекаются, потому что
  верхнюю границу задал пользователь.

`backend/designer/app.py` — у задачи появилось поле `warnings`, оно наполняется генерацией
и уходит в `GET /api/v1/jobs/{id}`.

`frontend`: тип `ApiJob.warnings`, жёлтая плашка под прогрессом (`.banner.warning`).

Документация: бейдж тестов в README без числа сценариев, в тексте тоже без числа;
`docs/test-run.md` — пометка, что адрес стенда живёт в переменной `DEPLOY_HOST`, и раздел
«Локальный запуск» (Docker, работа без ключа модели, регресс без модели); `MODELS.md` —
ссылки на карточки [openai/gpt-oss-20b](https://huggingface.co/openai/gpt-oss-20b) и
[Qwen/Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B), у обеих лицензия
`apache-2.0`, и честная оговорка про размер MoE.

## Тесты

- `test_short_deck_is_sent_back_with_a_way_to_grow` — на недоборе модель получает просьбу
  разбить слайды или добавить таблицу либо схему, и вторая попытка даёт нужный объём;
- `test_stubborn_short_deck_is_accepted_with_a_warning` — упрямая модель не оставляет
  пользователя без колоды, но предупреждение с числами записано;
- `test_deck_never_exceeds_the_requested_size` — перебор обрезается до запрошенного.
- `pytest -q`: 97 passed, 1 skipped.

## Результат

Колоды собираются в запрошенном объёме, а если материала действительно мало — это видно в
интерфейсе жёлтой плашкой, а не молча. Набор `samples/` пересобран этим же сервисом,
цифры — в [samples/README.md](../../samples/README.md).

Замечание на будущее: у мультимодальной модели карточка Hugging Face показывает 36B общих
параметров. Если предел ТЗ в 35B считают по общему числу, а не по активным 3B, VLM нужно
заменить — это одна переменная окружения.
