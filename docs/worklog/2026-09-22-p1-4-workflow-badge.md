# P1-4. Версия сценария генерации вернулась в интерфейс

**PR:** feat/p1-4-workflow-badge · **Автор:** DiFoxen + Claude · **Дата:** 2026-09-22

## Проблема

Сервис версионирует промпты: `GET /api/v1/workflow` отдаёт версию сценария, файл промпта
каждого агента, sha256 этих файлов и журнал изменений. В интерфейсе этого не было видно —
метод `api.workflow()` не вызывал никто. Для жюри это ровно та часть, которая показывает,
что промпты не пишутся на ходу: колода собрана конкретной версией, и её видно.

## Что сделано

- `services/presentationService.ts`: адаптер `workflow()` → `WorkflowInfo`. Служебные имена
  агентов (`outline`, `audit_image`, …) переводятся в понятные подписи, от sha256 остаётся
  первые 8 символов — этого хватает, чтобы сверить промпт с файлом в репозитории.
- `App.tsx`: в шапке рядом с «Как это работает» — кнопка «Сценарий 1.9.0». По клику
  открывается карточка: список агентов с файлами промптов и префиксами sha, ниже — почему
  появилась последняя версия. Закрывается кликом мимо и по Escape, как обычное меню.
  Если эндпоинт недоступен, кнопки просто нет: версия — справка, а не повод для ошибки.
- `simplified.css`: стили карточки; на узком экране она не вылезает за край.
- `vite.config.ts`: в режиме разработки vite проксирует `/api` на `VITE_DEV_API_PROXY`.
  Без этого фронтенд с локальной машины нельзя показать на работающем стенде — браузер
  блокирует запрос политикой CORS. README и `.env.example` описывают переменную.
- `api.ts`: убран неиспользуемый экспорт `apiConfigured` — он обещал локальный демо-режим,
  которого больше нет.

  (outline.v3.txt `ac065d8f`, audit.v1.txt `849e32a3`, audit.image.v1.txt `a28c122c`,
  condense.v1.txt `96b86510`, assets.v1.txt `cfb50321`) и запись журнала про 1.9.0;
- закрытие по Escape и кликом мимо проверено в браузере, на ширине 700 px карточка
  помещается в экран без горизонтальной прокрутки.
