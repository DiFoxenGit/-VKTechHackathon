# P2-14 (2/3). Проверка chart_without_data: диаграмма только по данным материалов

**PR:** feat/p2-14-chart-without-data (поверх repeated_content) · **Автор:** Claude, идея — PR #1 (kiritomp3) · **Дата:** 2026-09-24

## Проблема

Модели, которой нечего рисовать, проще всего пронумеровать этапы и построить по номерам
столбики: «Этап» — 1, 2, 3, 4. На слайде это выглядит как график роста, хотя данных за ним
нет. Проверка чисел в тезисах (`unverified_number`) такое не ловит по двум причинам:
значения диаграммы в текст не попадают, а однозначные числа она пропускает намеренно —
«три команды» и «3 команды» одно и то же.

## Что изменено

- `generation.fabricated_chart(visual, known)` → `(причина, порядковый ряд)`. Для bar и line
  каждое значение каждого ряда сверяется с числами материалов (`known_numbers`, та же
  нормализация, что у тезисов: «1 400» → 1400, «4,5» → 4.5). Ряд 1, 2, 3… длиной от трёх
  отклоняется всегда, даже если такие цифры в материалах есть.
- Генерация: план с такой диаграммой возвращается модели («значения — только числа из
  материалов дословно; нет данных — возьми схему, таблицу или список»). На последней
  попытке диаграмма снимается: слайд без графика лучше выдуманного графика.
- Аудит: `chart_without_data`. Порядковый ряд — **ошибка** (данных нет по построению),
  значение не из материалов — **предупреждение**, как `unverified_number` в тезисе.
  Автоисправления нет.

## Тесты

- `test_chart_values_are_checked_against_the_materials` — данные, пропущенное значение,
  порядковый ряд, дробное число, схема без значений;
- `test_content_audit_reports_chart_without_data` — ошибка на порядковом ряду,
  предупреждение на значении не из материалов;
- `test_chart_without_data_is_sent_back_to_the_model`, `test_last_attempt_drops_the_chart_without_data`;
- `pytest -q`: 129 passed, 9 skipped.

## Результат

Регресс, четыре шаблона × три варианта, оба плана: `chart_without_data` — 0 (диаграммы
плана «186 → 4 минуты» построены по числам материала), остальные числа без изменений,
ошибок 0.
