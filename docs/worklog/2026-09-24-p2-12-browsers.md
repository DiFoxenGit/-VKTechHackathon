# P2-12. Полный путь в Chrome, Firefox, Safari (WebKit) и Chromium — без ошибок

**PR:** fix/p2-12-browsers · **Автор:** Claude · **Дата:** 2026-09-24

## Проблема

ТЗ требует корректной работы в текущей и предыдущей версиях Chrome, Firefox, Safari и
Яндекс Браузера на macOS и Windows. Проверяли только в Chromium. Риски из плана: единицы
`cqw`, селектор `:has()`, элемент `<dialog>`, `backdrop-filter`, `dvh`.

## Разбор стилей

| Возможность | Где | Chrome / Яндекс | Firefox | Safari | Вывод |
|---|---|---|---|---|---|
| `cqw`, `container-type` | миниатюры шаблонов, холст слайда (32 места) | 105+ | 110+ | 16+ | поддержано в текущей и предыдущей версиях |
| `:has()` | `.modal.wide:has(.settings-content)` — только ширина окна настроек | 105+ | 121+ | 15.4+ | поддержано; без него окно просто шире на 330 px |
| `<dialog>`, `showModal()`, `::backdrop` | все модальные окна | 37+ | 98+ | 15.4+ | поддержано |
| `backdrop-filter` на `::backdrop` | размытие фона под окном | 76+ | 103+ | без префикса с 18, раньше `-webkit-` | **добавлен `-webkit-backdrop-filter`** |
| `dvh` | высота модального окна | 108+ | 101+ | 15.4+ | поддержано; **добавлен запасной `100vh`** перед `100dvh` |

Текущие версии на 24.09.2026: Chrome 153, Firefox 155, Safari 26, Яндекс Браузер на
Chromium того же поколения; предыдущие — на одну мажорную версию ниже. Всё из таблицы в них
поддержано; правки — страховка для Safari 17 и старых мобильных движков, вид не меняют.

## Прогон

`tools/browser_check.mjs` (Playwright) проходит путь пользователя в каждом движке и снимает
скриншот на каждом шаге: главная → бриф → «Создать презентацию» → структура → «Сверстать
варианты» → три варианта → редактор → правка заголовка слайда 2 (уходит на сервер, `PATCH`)
→ просмотр с замечаниями → закрытие по Escape → панель «Проверка слайдов» → «Скачать» →
PowerPoint → проверка, что скачан zip-файл PPTX. Интерфейс — master этой ветки
(`npm run dev`), бэкенд — стенд `158.160.225.35`.

| Движок | Версия | Шагов | Время | Вариантов | Правка сохранена | Escape закрыл окно | PPTX | Ошибок консоли / HTTP |
|---|---|---|---|---|---|---|---|---|
| Chromium (движок Chrome и Яндекс Браузера) | 153.0.8010.12 | 10/10 | 75 с | 3 | да | да | 431 КБ | 0 / 0 |
| Google Chrome (установленный) | 153.0.8010.53 | 10/10 | 61 с | 3 | да | да | 425 КБ | 0 / 0 |
| Firefox | 155.0 | 10/10 | 76 с | 3 | да | да | 426 КБ | 0 / 0 |
| WebKit (движок Safari) | 26.6 | 10/10 | 50 с | 3 | да | да | 427 КБ | 0 / 0 |

Правка заголовка доехала до файла: в скачанном PPTX на слайде 2 — «Проверка правки в
браузере». Сырые данные — [report.json](p2-12-browsers/report.json), сравнение экранов
Chrome / Firefox / WebKit — [варианты](p2-12-browsers/variants.jpg),
[редактор и проверка](p2-12-browsers/editor-audit.jpg), [просмотр](p2-12-browsers/preview.jpg).
Вёрстка интерфейса во всех движках одинакова; содержание колод разное, потому что каждый
прогон заново вызывает модель.

## Найденные различия и правки

- `frontend/src/styles.css`: `-webkit-backdrop-filter` и запасной `max-height: calc(100vh - 40px)`.
- `frontend/src/App.tsx`: имя скачанного файла — двоеточие в названии колоды давало двойной
  пробел («Инициатива  сервис…pptx»); пробелы теперь схлопываются. Во всех движках одинаково.
- Различий между движками в поведении не найдено.

## Что не проверено

- **Windows.** Прогон шёл на macOS. Движки те же, отличаются шрифты системы: интерфейс
  использует свои веб-шрифты (Manrope, Play), так что риск низкий, но глазами не смотрели.
- **Настоящий Safari и Яндекс Браузер.** Safari представлен WebKit 26.6 из Playwright —
  тот же движок; Яндекс Браузер — Chromium того же поколения. Для полной уверенности — один
  ручной проход в каждом.
- **Предыдущие версии** отдельно не запускали: вывод о них — по таблице поддержки выше.

