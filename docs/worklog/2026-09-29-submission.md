# Сдача решения: синхронизация main и презентация

**Ветка:** chore/sync-github-58 · **Автор:** DiFoxen + Claude · **Дата:** 2026-09-29

## Что было

PR #58 Степана (сценарий 1.12.0: сверка источников, нативные графики для сравнений,
полные архивы эталонов) слит 28.09 только в GitHub `main`. В SourceCraft `main` его не
было, поэтому деплой упал с «коммит не входит в origin/main», и стенд остался на 1.11.0.

## Что сделано

- Коммит `799681a` перенесён в ветку от SourceCraft `main` без изменений (fast-forward):
  его проверки на GitHub (pytest, frontend, Integration) зелёные.
- `docs/presentation.pdf` — презентация для сдачи на шаблоне ЛЦТ 2026: обязательные
  слайды 7–11 шаблона (команда Freak Studio, состав, история, коротко о решении) и
  описательная часть. Ссылка — в шапке и разделе «Документация» README.

PDF собран LibreOffice без шрифта Montserrat, поэтому гарнитура в нём подменена;
исходный PPTX хранится у команды.

## Эталоны на сценарии 1.12.0

После слияния (!15) и деплоя стенд работает на 1.12.0. Эталоны пересобраны на стенде
новым сборщиком (`--require-chart`), без ручных правок и повторных попыток:

| Шаблон | Слайдов | Сервер | Со скачиванием | Ошибок |
|---|---|---|---|---|
| VK Tech | 12 | 138 с | 244 с | 0 |
| VK WorkSpace | 10 | 194 с | 262 с | 2 на вариант (`unsupported_fact`) |
| VK Education | 12 | 95 с | 133 с | 0 |

Нативные графики — во всех девяти колодах. У VK WorkSpace модель пересчитала
«2 из 68» в «98%» и добавила общий вывод без опоры на материал — оба пункта отмечены
контекстным аудитом как ошибки. Колоды сохранены как есть: они показывают работу проверки.
Прежние цифры 25.09 (0 ошибок, 42–135 с) относились к сценарию 1.11.0 без обязательной
проверки содержания и из документации убраны.

## Гайд для проверяющих

`docs/test-run.md` переписан как единый гайд: стенд и путь по интерфейсу, четыре сценария
с готовыми значениями, проверка через HTTP API и `make_samples.py`, локальный запуск

сценарию 1.8: теперь ссылка стоит в шапке README, в быстром старте и в таблице документации.
