# P2-2: выделяемый и доступный поиску текст HTML-экспорта

**PR:** ветка `codex/p2-2-live-html` · **Автор:** Codex · **Дата:** 2026-09-20

## Проблема и причина

HTML содержал SVG из PDF с `text_as_path=True`: вместо букв получались
векторные контуры. Текст нельзя было выделить или найти. `lang="ru"` задавался
независимо от языка запроса. Сохранённый HTML отдавался из кэша ревизии.

## Что изменено

- `exporting.export_html`: `text_as_path=False`, живые SVG `text`/`tspan`.
  Повторная безопасная XML-сериализация оставляет кириллицу в UTF-8 вместо
  числовых сущностей, поэтому фразы ищутся и в исходном HTML-файле.
- `app.py`: `generation.language` передаётся в экспорт; для старых записей
  без языка сохранено значение `ru`. Язык и заголовок HTML экранируются.
- Маркер версии HTML позволяет пересоздать старый экспорт при первом запросе.
  Уже обновлённые файлы продолжают использовать кэш. PPTX/PDF не пересобираются.

## Тесты

`PYTHONPATH=backend python -m pytest backend/tests/test_html_export.py -q`:
**3 passed**.

- Настоящий PDF со встроенным Play и строкой «186 минут»: строка присутствует
  и в DOM, и в исходном HTML, найдены SVG-текстовые узлы, рост размера ≤ 1.5×.
- Язык `en-GB`, экранирование заголовка и атрибута языка, сохранение буквального
  `<script>` как текста без создания исполняемого элемента.
- HTTP-экспорт использует язык сохранённой генерации, заменяет старый HTML
  из кэша и повторно не перезаписывает уже актуальную выгрузку.

## Результат

Проверены PDF всех **12 колод** (4 реальных шаблона × 3 варианта, 12 слайдов),
полученные регрессионной джобой в LibreOffice после P0-1. Во всех выгрузках
«186 минут» ищется как в DOM, так и в файле.

| Шаблон | Новый HTML / прежний SVG с кривыми, по трём вариантам |
|---|---|
| VK Tech | 0.784–0.787 |
| VK WorkSpace | 0.837–0.838 |
| ЛЦТ2026 | 0.837–0.838 |
| VK Education | 0.404–0.519 |

Для сравнения старый размер посчитан как сумма прежних SVG без небольшой
HTML-обёртки, новый — полный HTML: оценка консервативна. Ни одна выгрузка не
выросла. Рендеры и шаблоны организаторов в Git не включены.

Живой SVG-текст использует доступные браузеру гарнитуры; если корпоративного
шрифта на устройстве нет, браузер может заменить его. PDF остаётся вариантом
с фиксированным видом для печати.
