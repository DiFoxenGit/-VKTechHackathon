# Как прогнать сервис самому

Всё развёрнуто и работает: **http://158.160.225.35**

Открывается один экран. Ниже — готовые значения: их можно вставлять как есть.
Ничего настраивать не нужно, модель и шаблоны уже подключены.

---

## Сценарий 1. Защита инициативы перед руководством

**Файл для загрузки:** `samples/source/материал-инициатива.md`
(в интерфейсе — кнопка **«Материалы»** в блоке «Бриф»)

**Шаблон:** `VK Tech шаблон`

**Бриф** — вставить в большое поле:

```
Защита инициативы перед руководством: предложить сервис автоматической вёрстки презентаций, показать эффект пилота в цифрах и попросить решение о запуске на всю компанию.
```

**Назначение:** `Инициатива`
**Слайдов:** `10`
**«Проверка содержания моделью»** — галочка над кнопками; можно включить, добавит ~20 секунд

Дальше: **«Собрать структуру»** → посмотреть и при желании поправить заголовки
и тезисы → **«Сверстать три варианта»**. Можно и сразу нажать
**«Сгенерировать»** — структура соберётся по дороге.

Ожидаемо: 25–60 секунд на всю задачу, три варианта, ноль ошибок аудита.
Цифры на слайдах — только те, что есть в материале: 186 минут, 74 минуты,
19 из 42, 68 колод, 1 400 рублей.

## Сценарий 2. Продукт, другой шаблон, другой тип рассказа

**Файл для загрузки:** `samples/source/материал-продукт.md`

**Шаблон:** `VK_WorkSpace_Клиентская_конференция_Шаблон_03`

**Бриф:**

```
Представить платформу видеовстреч «Созвон» продуктовому комитету: показать проблему, ценность для команд, отличие от внешних сервисов, результаты пилота и попросить решение о переводе компании.
```

**Назначение:** `Продукт`
**Слайдов:** `12`

Смысл сценария — увидеть, что состав слайдов меняется вместе с назначением:
у продукта появляются рынок, ценность для сегментов и отличие от альтернатив,
которых нет в «Инициативе».

Прогон 17 сентября: 12 слайдов за 64 секунды, ноль ошибок аудита. Состав вышел
такой: проблема рынка → продукт → ценность для сегментов → отличия → метрики
пилота с диаграммой → экономика → дорожная карта → риски → запрос решения.

## Сценарий 3. Тот же материал на третьем шаблоне

Чтобы увидеть, что дизайн-система берётся из файла, а не зашита в код:
повторить сценарий 1, поменяв только шаблон на `Шаблон презентации VK Education`.
Текст будет тот же, оформление — другое: своя палитра, свои гарнитуры, свои
страницы-прототипы.

---

## Свой шаблон

Кнопка **«Загрузить PPTX»** в блоке «Шаблон» принимает любой .pptx до 50 МБ.
Сервис разберёт его сам: гарнитуры, шкала кеглей, палитра, поля, направляющие,
страницы-прототипы с их ролями. Имён макетов в коде нет — на финале это и
проверяют.

После загрузки у карточки шаблона видно паспорт дизайн-системы: сколько
страниц-прототипов разобрано, какие цвета и шрифты найдены.

---

## Свои материалы

Принимаются `.txt`, `.md`, `.csv`, `.json`, `.docx`, `.pptx` и `.pdf` с текстовым
слоем (сканы без текста — нет). Можно загрузить несколько файлов сразу.

Важно: сервис не выдумывает цифры. Если числа нет в материалах, оно не появится
на слайде, а если модель всё же его напишет — аудит пометит его как
неподтверждённое.

## На что смотреть в результате

| Где | Что проверять |
|---|---|
| Три вкладки вариантов | одна и та же структура разложена по-разному: вертикально, в две колонки, с акцентом |
| Панель аудита | находки с объяснением; галочки у исправимых и кнопка «Исправить выбранные»; отдельно — «Проверить по изображению»: слайд уходит картинкой мультимодальной модели |
| Превью слайда | красная подсветка там, где аудит нашёл проблему |
| Кнопки экспорта | `PPTX` открывается и редактируется, `PDF` для показа, `HTML` для веба |
| Бейдж «воркфлоу 1.8.0» в шапке | версия агентов, файлы промптов, их sha256 и причина последнего изменения |
| Переключатель темы справа | светлая и тёмная |

**Проверить главное — что слайды не картинки:** скачать PPTX, открыть в
PowerPoint и щёлкнуть по тексту. Он редактируется, диаграмма открывается как
диаграмма, таблица как таблица.

## Если что-то не так

| Симптом | Что это |
|---|---|
| «Модель не вернула корректный ответ» | открытая модель на 20B иногда не справляется с материалом; повторить запуск |
| Слайдов меньше, чем просили | материала не хватило: сервис лучше сделает 7 честных слайдов, чем 12 с водой |
| Долго на первом запросе после перезапуска | сервис разбирает шаблоны и измеряет их фон один раз при старте |
| Пустая страница | проверить, что открыт `http://158.160.225.35` без `https` — сертификата пока нет, домена тоже |
