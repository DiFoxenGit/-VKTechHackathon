`924f7b0` выполнены **две платные отправки**: короткий JSON-запрос и одно полное

## Изменения инструментов

Для одной короткой пробы существующего транспорта:

```powershell
python tools/check_inference.py --env-file .env.local --accept-fallback --attempts 1 --output output/genapi-limited/probe.json
```

`--accept-fallback` принимает только явно настроенный резерв с совпадающим именем
модели. Отчёт раздельно показывает `primary_model_verified` и
`provider_fallback_used`. Режим запрещает несколько попыток и совмещение с
генерацией сервиса, у которой собственный бюджет. Без флага проверка по-прежнему
требует фактический ответ выбранного основного провайдера.

В учёт добавлено сохранение GenAPI task ID сразу после принятия задачи, включая
таймаут опроса. Формат `response_id` — `genapi:<request_id>`; это позволяет позже
проверить уже принятую задачу через GET без повторной платной отправки. Для
немедленного ответа сохраняется response ID, если он предоставлен. Эта правка
сделана после живых прогонов и проверена управляемыми ответами; новых платных
запросов ради неё не выполнялось. **144 целевых теста прошли.**

## Что остаётся

Полная живая матрица трёх шаблонов, версия B, другой период, независимые повторы,
браузерная приёмка нового провайдера и общий таймер девяти результатов ещё не
выполнены. Их нельзя заменить результатом одного задания. Следующий живой этап
следует запускать отдельно с явным небольшим бюджетом. Изображения
остаются отложенными по просьбе Степана.
