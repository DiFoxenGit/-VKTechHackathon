# Слайд — фронтенд дизайнера презентаций

Интерактивный прототип для кейса VK Tech, ЛЦТ 2026. React 19, TypeScript, Vite. Интерфейс на русском языке, адаптирован для настольного экрана и небольших окон.

Основной сценарий: **описать идею → нажать «Создать презентацию» → получить готовую презентацию**. По умолчанию используются 10 слайдов и VK Tech. Шаблоны, аудитория и объём скрыты в «Настроить». Структура, три варианта дизайна и проверка доступны в меню редактора и не являются обязательными шагами.

## Запуск

Требуется Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://127.0.0.1:5173).

```bash
npm run build
npm run preview
```

Сборка находится в `dist/`. Переменные окружения и ключи для демонстрации не нужны. Шрифты поставляются с приложением, внешние сервисы во время работы не вызываются.

## Что работает

- Бриф, готовые примеры, аудитория, цель и количество слайдов.
- Чтение материалов TXT/MD до 2 МБ и 50 000 символов, включая перетаскивание файла.
- Библиотека трёх шаблонов с реальными метаданными из предоставленного архива.
- Импорт цветов, шрифта и количества макетов из произвольного PPTX до 50 МБ. Исходный файл не отправляется на сервер.
- Редактирование структуры: заголовки, тезисы, добавление, удаление и изменение порядка.
- Три оформления одинакового содержания, миниатюры, редактор текста и полноэкранный просмотр слайдов.
- Проверки пустого содержимого, длинного текста, повторов и лишних пробелов.
- Экспорт настоящего PPTX с редактируемыми текстовыми блоками и фигурами, автономного HTML и печать в PDF.
- Библиотека презентаций с поиском, удалением и сохранением в localStorage. Каждая презентация хранит свой исходный бриф.
- Проверка формата/размера файлов, сообщения об ошибках, доступные подписи кнопок, управление модальными окнами с клавиатуры.

## Границы демоверсии

ИИ и бэкенд **не подключены**. Структура собирается детерминированно из пользовательского текста без добавления фактов. Если текста мало для выбранного числа слайдов, появляются пустые разделы и замечания проверки.

Карточки стилей иллюстрируют оформление. Импорт PPTX извлекает **метаданные**, а не оригинальные мастер-слайды, изображения, графики и композиции. Результат использует собственные три макета демоверсии, всегда 16:9. Количество макетов в карточке относится к исходному файлу.

Аудит локальный: он не проверяет достоверность, смысл, пересечения объектов, правила композиции и все критерии ТЗ. Длинный текст требует ручного сокращения или распределения между слайдами. Экспорт PPTX отклоняется с сообщением, если текст не удаётся вместить.

PDF создаётся через окно печати браузера: выберите **«Сохранить как PDF»**, включите фоновую графику и отключите колонтитулы, если браузер не применил настройки страницы. HTML использует системный шрифт, если шрифт шаблона не установлен на устройстве получателя. Для точного отображения PPTX шрифт шаблона также должен быть установлен.

Данные хранятся только в текущем браузере и не синхронизируются. При очистке данных сайта они исчезнут. При недоступном хранилище интерфейс покажет предупреждение — скачайте результат до закрытия страницы.

## Подключение бэкенда

Точка интеграции: `src/services/presentationService.ts`. Компонент вызывает типизированный `PresentationService.createOutline(brief): Promise<Deck>`. Замените демонстрационный адаптер HTTP-клиентом. Форматы `Brief`, `Deck`, `Slide`, `Template` и `AuditIssue` находятся в `src/types.ts`.

Дальнейшие серверные операции стоит вынести в методы этого же слоя: импорт шаблона, запуск генерации, статус задания, аудит и экспорт. API-контракт ещё не задан; текущий код не предполагает существующих эндпоинтов и не содержит секретов. При подключении сервера обновите подписи деморежима, хранения и поддерживаемых форматов.

## Структура проекта

```text
src/
  App.tsx                         экраны и пользовательские действия
  styles.css                      дизайн и адаптивная вёрстка
  simplified.css                  простой главный экран и компактная навигация
  engine.ts                       локальная сборка, PPTX, аудит, экспорт
  types.ts                        доменные типы
  services/presentationService.ts граница интеграции API
  main.tsx                        запуск и локальные шрифты
public/favicon.svg
```

## Материалы кейса

Метаданные библиотеки прочитаны из `Датасет.zip`: VK Tech (54 слайда / 39 макетов), VK WorkSpace (29 / 15), VK Education (55 / 30). В предоставленном архиве нет отдельного контент-пакета. Тексты внутри шаблонов не использованы как бизнес-факты.

PDF с заданием использован для определения пользовательского сценария. Шаблон презентации ЛЦТ относится к оформлению питча, а не к дизайну интерфейса. Исходные файлы не изменены и не включены в репозиторий.
