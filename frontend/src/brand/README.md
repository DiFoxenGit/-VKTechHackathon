# Бренд-система интерфейса

Всё оформление сервиса живёт здесь. Компоненты не знают про конкретные цвета:
они обращаются к токенам, поэтому тема переключается без правки разметки.

| Файл | Что внутри |
|---|---|
| `tokens.css` | палитра, поверхности, текст, тени, радиусы, шаг сетки, типографика, обе темы |
| `theme.ts` | выбор темы: светлая, тёмная, как в системе; хранится в localStorage |
| `Logo.tsx` | знак и логотип сервиса; цвета берутся из токенов, поэтому работают в обеих темах |

## Темы

Светлая тема — значения на `:root`. Тёмная переопределяет только те токены, у
которых меняется роль, и делает это дважды: в `@media (prefers-color-scheme: dark)`
для системной настройки и в `:root[data-theme='dark']` для явного выбора
пользователя. Выбор ставится атрибутом на `<html>` ещё в `index.html`, до первого
кадра, иначе тёмный интерфейс моргает белым фоном.

## Палитра

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--brand-500` | `#0077ff` | `#4d9bff` | основной акцент, кнопки, активные состояния |
| `--accent-500` | `#ff3885` | `#ff5c9b` | точка внимания: знак, контекстные метки |
| `--ground` | `#f4f6fa` | `#0e1116` | фон страницы |
| `--surface` | `#ffffff` | `#171b22` | карточки |
| `--surface-2` | `#eef1f6` | `#1f242d` | вложенные блоки, поля ввода |
| `--ink` / `--ink-2` / `--ink-3` | `#14161c` / `#454b57` / `#6b7280` | `#f2f4f8` / `#c3c9d4` / `#8e97a6` | основной, вторичный и третичный текст |
| `--error-500`, `--warn-500`, `--ok-500` | — | — | статусы аудита |

## Правила

- Новый цвет объявляется токеном в `tokens.css`, а не хардкодится в компоненте.
- Отступы берутся из шкалы `--step-1…--step-7`, размеры текста — из `--text-*`.
- Иконки — `lucide-react`, размер 15–18 px, всегда с подписью или `aria-label`.
- Анимации отключаются при `prefers-reduced-motion`.
