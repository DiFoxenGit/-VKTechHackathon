# Аудит и тесты

## Контекстные проверки по изображению слайда

Слайд рендерится в PNG и уходит мультимодальной модели с одиннадцатью вопросами Приложения 1 («да» = со слайдом всё в порядке). Проверяются заголовок-вывод, соответствие содержимого заголовку, пересказ одним предложением, подтверждение фактов материалами, наличие содержания, релевантность визуализаций, отсутствие служебного мусора, опечатки, единый язык, осмысленность строк таблицы и читаемость.

Запуск: `POST /presentations/{id}/audit?visual=true`. Модель задаётся переменными `DESIGNER_VLM_MODEL` и `DESIGNER_VLM_BASE_URL`; без них контекстная проверка идёт по структурированному тексту (`?contextual=true`). Находки помечены категорией `contextual` и элементом `slide_image`, автоматически не исправляются: смысл правит человек.

Слайды проверяются параллельно, сбой на одном слайде не роняет остальные. На колоде из восьми слайдов проверка занимает около минуты.

## Проверки записанного файла

Четыре пункта Приложения 1 честно проверяются только по готовому PPTX, а не по модели
вёрстки: решение об этих вещах принимает экспорт. После записи каждой ревизии файл
открывается заново, и находки попадают в тот же отчёт аудита, что и остальные.

| Код | Проверка | Ориентир из Приложения 1 |
|---|---|---|
| file_broken | Файл не открывается или архив повреждён | файл не открывается |
| raster_slide | На слайде нет редактируемых объектов, только картинка | слайд оказался картинкой |
| branding_moved | Элемент шаблона (логотип, колонтитул, декор) сдвинут относительно страницы-прототипа больше чем на 0,4% размера слайда; фигуры сопоставляются по паре «номер и имя» | логотип или колонтитул сдвинуты с положенного места |
| chart_labels | У диаграммы нет легенды (когда рядов больше одного), подписей осей или подписей значений | у диаграммы нет подписей осей, единиц или легенды |

Результат целиком лежит в `export_check` записи презентации: открывается ли файл, сколько
слайдов и редактируемых объектов, какие слайды собраны картинками, что с диаграммами и с
брендингом. В интерфейсе он виден строкой над списком замечаний.

## Картинки, иконки и фактоиды

Фактоид (крупная цифра с подписью) проверяется как текст: гарнитура, кегли цифры и подписи на шкале шаблона (`font_size_off_scale`), оценка переполнения подписи (`text_overflow`), контраст подписи к фону (`low_contrast`). Цифра красится акцентом только при контрасте от 3:1 — порог WCAG для крупного кегля. Плитки фактоидов выровнены шагом сетки, поэтому `misaligned` к ним со второй колонки не применяется. Иконки, заменившие значки-образцы шаблона, стоят в рамках дизайнера (`from_template`).

Картинки на слайд вставляются без растяжения по построению: иллюстрация вписывается в свои пропорции, фото кадрируется. На слайдах со своей композицией и с диаграммой мелкие образцы страницы не переносятся и не проверяются на наезд. Подробности — [docs/visual-assets.md](docs/visual-assets.md).

## Детерминированные проверки

Выполняются после верстки каждого варианта, после редактирования и выбранных исправлений. Один и тот же JSON слайдов и источники дают одинаковые ID и результаты.

| Код | Проверка | Ориентир из Приложения 1 | Автоисправление |
|---|---|---|---|
| out_of_bounds | Блок вне границ слайда | элемент вышел за границы | Перемещение/ограничение рамки |
| margin_encroachment | Блок заходит в поля у краёв; границы взяты из шаблона | контент заходит в поля | Сдвиг внутрь полей |
| misaligned | Левый край блока не совпадает ни с другим блоком, ни с краем рабочей области | блоки не выровнены по направляющим | Привязка к ближайшей направляющей |
| overlap | Пересечение контентных блоков | два блока наложились | Нет, требуется решение пользователя |
| branding_overlap | Блок перекрывает логотип, колонтитул или декор шаблона | блоки не наезжают на брендинг | Нет |
| text_overflow | Эвристическая оценка строк по ширине рамки | текст не поместился в рамку | Кегль вниз до 10 pt, затем рост рамки до нижнего поля; если не помогло — находка помечается неисправимой с причиной |
| font_not_in_template | Гарнитура отсутствует в токенах | шрифт не из шаблона | Нет |
| font_missing_glyphs | В гарнитуре нет символов текста: cmap встроенного/системного шрифта, затем известное отсутствие кириллицы | текст должен читаться | Нет; выбор кириллической гарнитуры шаблона выполняется при разборе |
| font_variety | В колоде больше двух гарнитур | гарнитур больше двух | Нет |
| font_size_off_scale | Кегль вне типографической шкалы шаблона: 5–9 ступеней, кластеры близких значений, взвешенные объёмом текста | кегль не из шкалы | Привязка к ближайшему кеглю шкалы |
| color_not_in_palette | Цвет текста вне палитры шаблона: цвета, которыми в шаблоне действительно что-то покрашено | цвет не из палитры | Замена на читаемый цвет палитры |
| low_contrast | Контраст текста к фону ниже 4.5:1 по WCAG | контраст ниже 4.5:1 | Нет |
| layout_not_from_template | Слайд ссылается на макет вне шаблона | слайд собран не на макете шаблона | Нет |
| fill_ratio | Оценка заполнения слайда вне диапазона 25–75% | слайд заполнен меньше четверти/больше трёх четвертей | Нет |
| bullet_count | Более 6 тезисов | больше 6 буллетов | Нет, нельзя молча удалять содержание |
| bullet_length | Более 15 слов в тезисе | буллет длиннее 15 слов | Нет |
| table_size | Более 7 строк или 5 колонок | таблица больше 7 строк или 5 колонок | Нет |
| chart_series | Более 5 серий | больше 5 серий на диаграмме | Нет |
| chart_labels | У диаграммы нет единицы измерения по оси значений; отдельно отмечается, если и ряд без названия | нет подписей осей, единиц или легенды | Нет |
| chart_too_small | Диаграмма занимает меньше 25% высоты слайда | нет подписей осей, единиц или легенды (расширение: сжатую диаграмму не прочесть) | Увеличение рамки вниз, при нехватке — вверх, не заходя на соседний блок |
| foreign_language | Подписи внутри графика, таблицы или схемы написаны не на языке колоды | вся колода на одном языке | Нет, текст правит пользователь |
| deck_language | Слайд написан не на языке колоды или не на запрошенном языке; имена продуктов и технические токены не в счёт | вся колода на одном языке | Нет, текст правит пользователь |
| image_stretched | Пропорции рамки картинки расходятся с её собственными больше чем на 3% (с учётом обрезки) | картинка растянута | Восстановление пропорций по короткой стороне |
| text_over_image | Фон страницы измерен по рендеру: находка появляется там, где фон тёмный и пёстрый и вёрстка была вынуждена положить подложку. Спокойный фон претензий не вызывает, даже если в XML он объявлен картинкой; без измерения предупреждение остаётся с пометкой «фон не измерен» | контраст текста к фону | Нет, подложка ставится при вёрстке |
| chart_without_data | Значения диаграммы сверяются с числами материалов: ряд 1, 2, 3… (номера вместо данных) — ошибка, значение, которого нет в материалах дословно, — предупреждение | у диаграммы нет подписей осей, единиц или легенды (расширение: цифры на слайде — только из материалов) | Нет; при генерации такой план возвращается модели, на последней попытке диаграмма снимается |
| chart_single_value | В диаграмме одно значение | у диаграммы нет подписей осей, единиц или легенды (расширение) | Нет |
| diagram_steps | В схеме больше 6 элементов | плотность содержания | Нет |
| text_too_small | Кегль текста или подписей схемы мельче 10 pt | текст нечитаем | Подъём до ближайшей ступени шкалы не ниже 10 pt |
| word_break | Самое длинное слово шире рамки или элемента схемы и будет перенесено по слогам | текст обрезан или нечитаем | Нет, решает вёрстка или сокращение подписи |
| placeholder | Lorem ipsum, XXX, TODO, «вставьте текст» | остался текст-заглушка | Нет |
| empty_content | Только заголовок | пустой слайд или слайд с одним заголовком | Нет |
| duplicate_slide | Повтор заголовка и тезисов | два слайда дублируют друг друга | Нет |
| repeated_content | Тот же тезис или пункт схемы уже сказан на другом слайде или совпадает с заголовком (своим или чужим); сравнение без учёта регистра, «ё» и пунктуации | два слайда дублируют друг друга (расширение: повтор по частям) | Нет; при генерации план с повторами возвращается модели, на последней попытке повторы снимаются |
| source_reference | Не указаны/неизвестны ссылки на источники | расширение ориентира | Нет |
| unverified_number | Число из текста отсутствует дословно в материалах | все цифры есть в исходных материалах | Нет; это эвристический сигнал, не доказательство ложности |

Шкала кеглей (`tokens.font_sizes`) — не список всех встреченных значений, а ступени: близкие кегли сливаются, вес ступени считается по объёму набранного ею текста, всё ниже 9 pt уходит в `tokens.caption_sizes` (сноски, подписи в иконках), всё выше 11% высоты слайда отбрасывается как декоративная надпись. Палитра (`tokens.colors`) собирается из цветов, которыми в шаблоне что-то покрашено; цвета темы попадают в неё только по ссылке `schemeClr`, а целиком — лишь когда явных цветов в файле нет вовсе.

Поля, направляющие и палитра берутся из разобранного шаблона, а не из констант, поэтому проверки работают и на ранее не виденном файле. `font_variety` относится ко всей колоде и приходит без `slide_index`.

Проверка целостности экспорта выполняется на каждом сохранении ревизии (`export_check` в записи презентации): архив открывается, число слайдов сверяется с моделью, и каждый слайд обязан содержать редактируемые объекты. Слайд, состоящий только из растрового изображения, приводит к ошибке экспорта, а не к молчаливой выгрузке.

Валидатор до верстки отклоняет только то, что невозможно отрисовать: несовпадение длин серий и категорий, строки таблицы не по числу колонок, NaN/Infinity, пустые данные визуализации. Плотность (размер таблицы, число серий, отсутствие единиц) относится к качеству, поэтому она не блокирует генерацию, а приходит в отчёт аудита, где пользователь решает сам.

## Контекстуальные проверки

Запускаются внутри генерации с `contextual_audit=true` или отдельно POST audit?contextual=true при настроенном провайдере. В генерации общая структура проверяется один раз для всех трёх вариантов. Вход: структурированный контент слайдов и источники. Проверяются неподтверждённые факты, соответствие заголовка, логика повествования, язык, опечатки, служебный мусор. Ответ отмечен category=contextual, input=structured_text. Это не VLM-аудит изображения. При отсутствии настройки или ошибке модели возвращается ошибка, а не ложный результат «всё хорошо».

## Область покрытия

Детерминированные проверки покрывают разделы «Вёрстка», «Шаблон», «Плотность» и «Целостность» Приложения 1, кроме пунктов, требующих растрового анализа: читаемость растровых элементов. Пропорции изображений проверяются по геометрии: сервис своих картинок не вставляет, но страница шаблона приходит на слайд вместе со своими, и `image_stretched` сравнивает рамку с собственными пропорциями картинки с учётом обрезки. `deck_language` относится ко всей колоде и приходит без `slide_index`. Контраст считается по WCAG от разобранных токенов фона и текста, а не по пикселям рендера: градиентный или фотографический фон приводится к ближайшему сплошному цвету. Оценка переполнения и заполнения приблизительная, она моделирует ширину строки по кеглю и не учитывает все особенности гарнитур. Проверка выравнивания опирается на взаимные края блоков и рабочую область, а не на все авторские направляющие. Сервер отдаёт SVG-превью с прямоугольниками проблем через preview?highlight=true; интерфейс показывает его в окне просмотра слайда и умеет убирать рамки переключателем. Рамка есть не у каждой находки: `fill_ratio`, `source_reference`, `deck_language` и подобные относятся к слайду или колоде целиком, и на превью их не обвести — они видны текстом в панели проверки.

Подписи схем (пиктограммы, процесс, таймлайн, сравнение) набираются одним кеглем на всю схему, не мельче 10 pt. Если подписи не помещаются целыми словами, схема меняет раскладку — значки уходят в два ряда, шевроны разворачиваются в столбик, — а не уменьшает шрифт. Одна и та же формула (`visuals.label_plan`) считает кегль при экспорте и проверяет его в аудите.

Подписи значений и единица измерения пишутся в каждую диаграмму при экспорте: без них столбец 4 рядом со 186 не читается. Заголовок оси значений горизонтальный, при одном ряде он же несёт название ряда вместо легенды.

Экспорт сохраняет редактируемость новых текстов, таблиц, графиков и фигур. Проверки целостности итогового ZIP, открытия PPTX и типов объектов выполняются интеграционными тестами. Это не заменяет проверку в Microsoft PowerPoint и визуальную оценку всех возможных неизвестных шаблонов.

## Автоматические тесты

`presenton-main/servers/fastapi/tests/designer/test_pipeline.py`:

- Полный HTTP-цикл на синтетическом неизвестном шаблоне.
- Каждый из трёх приложенных VK-шаблонов, по три варианта.
- Открытие PPTX, число слайдов, native charts/tables/text, целостность ZIP.
- Различимость геометрии вариантов.
- Загрузка материалов, дедупликация, повреждённый файл, пустой контент.
- Несовпадение числа слайдов и ошибки visual schema.
- Каждая новая проверка проверена дважды: срабатывает на намеренно испорченном слайде и молчит на чистой колоде по всем трём шаблонам датасета.
- Автоисправления полей, кегля, цвета и выравнивания; невыбранная проблема остаётся.
- Проверка целостности экспорта: файл открывается, число слайдов совпадает, объекты редактируемые.
- Выборочные исправления: невыбранная проблема остаётся.
- Редактирование, конфликт ревизий, доступ к старому PPTX.
- Bearer token, CORS preflight, восстановление статуса после перезапуска.
- Контракт OpenAI-compatible API и ошибочный ответ (MockTransport).
- Ошибка фоновой генерации видна через статус задачи.
- PDF/HTML проверяются, когда LibreOffice установлен; иначе тест явно skipped.

Реальный инференс и нагрузочные испытания требуют выбранной модели/провайдера. `scripts/demo_backend.py` создаёт девять презентаций из одного контента для воспроизводимого демонстрационного прогона.
