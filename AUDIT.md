# Аудит и тесты

## Контекстные проверки по изображению слайда

Слайд рендерится в PNG и уходит мультимодальной модели с одиннадцатью вопросами Приложения 1 («да» = со слайдом всё в порядке). Проверяются заголовок-вывод, соответствие содержимого заголовку, пересказ одним предложением, подтверждение фактов материалами, наличие содержания, релевантность визуализаций, отсутствие служебного мусора, опечатки, единый язык, осмысленность строк таблицы и читаемость.

Запуск: `POST /presentations/{id}/audit?visual=true`. Модель задаётся переменными `DESIGNER_VLM_MODEL` и `DESIGNER_VLM_BASE_URL`; без них контекстная проверка идёт по структурированному тексту (`?contextual=true`). Находки помечены категорией `contextual` и элементом `slide_image`, автоматически не исправляются: смысл правит человек.

Слайды проверяются параллельно, сбой на одном слайде не роняет остальные. На колоде из восьми слайдов проверка занимает около минуты.

## Детерминированные проверки

Выполняются после верстки каждого варианта, после редактирования и выбранных исправлений. Один и тот же JSON слайдов и источники дают одинаковые ID и результаты.

| Код | Проверка | Ориентир из Приложения 1 | Автоисправление |
|---|---|---|---|
| out_of_bounds | Блок вне границ слайда | элемент вышел за границы | Перемещение/ограничение рамки |
| margin_encroachment | Блок заходит в поля у краёв; границы взяты из шаблона | контент заходит в поля | Сдвиг внутрь полей |
| misaligned | Левый край блока не совпадает ни с другим блоком, ни с краем рабочей области | блоки не выровнены по направляющим | Привязка к ближайшей направляющей |
| overlap | Пересечение контентных блоков | два блока наложились | Нет, требуется решение пользователя |
| branding_overlap | Блок перекрывает логотип, колонтитул или декор шаблона | логотип/колонтитул сдвинуты | Нет |
| text_overflow | Эвристическая оценка строк по ширине рамки | текст не поместился в рамку | Уменьшение кегля в пределах шкалы, не ниже 12 pt |
| font_not_in_template | Гарнитура отсутствует в токенах | шрифт не из шаблона | Нет |
| font_variety | В колоде больше двух гарнитур | гарнитур больше двух | Нет |
| font_size_off_scale | Кегль вне типографической шкалы шаблона | кегль не из шкалы | Привязка к ближайшему кеглю шкалы |

| low_contrast | Контраст текста к фону ниже 4.5:1 по WCAG | контраст ниже 4.5:1 | Нет |

| bullet_count | Более 6 тезисов | больше 6 буллетов | Нет, нельзя молча удалять содержание |
| bullet_length | Более 15 слов в тезисе | буллет длиннее 15 слов | Нет |
| table_size | Более 7 строк или 5 колонок | таблица больше 7 строк или 5 колонок | Нет |
| chart_series | Более 5 серий | больше 5 серий на диаграмме | Нет |
| chart_labels | У диаграммы нет единицы измерения по оси значений | нет подписей осей, единиц или легенды | Нет |
| foreign_language | Подписи внутри графика, таблицы или схемы написаны не на языке колоды | вся колода на одном языке | Нет, текст правит пользователь |
| text_over_image | Контент лежит на фотографии или пёстром фоне шаблона; под него добавлена подложка | контраст текста к фону | Нет, подложка ставится при вёрстке |
| chart_single_value | В диаграмме одно значение | у диаграммы нет подписей осей, единиц или легенды (расширение) | Нет |
| diagram_steps | В схеме больше 6 элементов | плотность содержания | Нет |
| placeholder | Lorem ipsum, XXX, TODO, «вставьте текст» | остался текст-заглушка | Нет |
| empty_content | Только заголовок | пустой слайд или слайд с одним заголовком | Нет |
| duplicate_slide | Повтор заголовка и тезисов | два слайда дублируют друг друга | Нет |
| source_reference | Не указаны/неизвестны ссылки на источники | расширение ориентира | Нет |
| unverified_number | Число из текста отсутствует дословно в материалах | все цифры есть в исходных материалах | Нет; это эвристический сигнал, не доказательство ложности |

Поля, направляющие и палитра берутся из разобранного шаблона, а не из констант, поэтому проверки работают и на ранее не виденном файле. `font_variety` относится ко всей колоде и приходит без `slide_index`.

Проверка целостности экспорта выполняется на каждом сохранении ревизии (`export_check` в записи презентации): архив открывается, число слайдов сверяется с моделью, и каждый слайд обязан содержать редактируемые объекты. Слайд, состоящий только из растрового изображения, приводит к ошибке экспорта, а не к молчаливой выгрузке.

Валидатор до верстки отклоняет только то, что невозможно отрисовать: несовпадение длин серий и категорий, строки таблицы не по числу колонок, NaN/Infinity, пустые данные визуализации. Плотность (размер таблицы, число серий, отсутствие единиц) относится к качеству, поэтому она не блокирует генерацию, а приходит в отчёт аудита, где пользователь решает сам.

## Контекстуальные проверки

Запускаются внутри генерации с `contextual_audit=true` или отдельно POST audit?contextual=true при настроенном провайдере. В генерации общая структура проверяется один раз для всех трёх вариантов. Вход: структурированный контент слайдов и источники. Проверяются неподтверждённые факты, соответствие заголовка, логика повествования, язык, опечатки, служебный мусор. Ответ отмечен category=contextual, input=structured_text. Это не VLM-аудит изображения. При отсутствии настройки или ошибке модели возвращается ошибка, а не ложный результат «всё хорошо».

## Область покрытия

Детерминированные проверки покрывают разделы «Вёрстка», «Шаблон», «Плотность» и «Целостность» Приложения 1, кроме пунктов, требующих растрового анализа: пропорции вставленных изображений и читаемость растровых элементов (сервис не вставляет изображения — задание со звёздочкой не подключено). Контраст считается по WCAG от разобранных токенов фона и текста, а не по пикселям рендера: градиентный или фотографический фон приводится к ближайшему сплошному цвету. Оценка переполнения и заполнения приблизительная, она моделирует ширину строки по кеглю и не учитывает все особенности гарнитур. Проверка выравнивания опирается на взаимные края блоков и рабочую область, а не на все авторские направляющие. Сервер отдаёт SVG-превью с прямоугольниками проблем через preview?highlight=true; интерфейс выбора реализует отдельный фронтенд.

Экспорт сохраняет редактируемость новых текстов, таблиц, графиков и фигур. Проверки целостности итогового ZIP, открытия PPTX и типов объектов выполняются интеграционными тестами. Это не заменяет проверку в Microsoft PowerPoint и визуальную оценку всех возможных неизвестных шаблонов.

## Автоматические тесты

`presenton-main/servers/fastapi/tests/designer/test_pipeline.py`:

- Полный HTTP-цикл на синтетическом неизвестном шаблоне.
- Каждый из трёх приложенных VK-шаблонов, по три варианта.
- Открытие PPTX, число слайдов, native charts/tables/text, целостность ZIP.
- Различимость геометрии вариантов.
- Загрузка материалов, дедупликация, повреждённый файл, пустой контент.
- Несовпадение числа слайдов и ошибки visual schema.
- Каждая новая проверка проверена дважды: срабатывает на намеренно испорченном слайде и молчит на чистой колоде по всем трём шаблонам датасета.
- Автоисправления полей, кегля, цвета и выравнивания; невыбранная проблема остаётся.
- Проверка целостности экспорта: файл открывается, число слайдов совпадает, объекты редактируемые.
- Выборочные исправления: невыбранная проблема остаётся.
- Редактирование, конфликт ревизий, доступ к старому PPTX.
- Bearer token, CORS preflight, восстановление статуса после перезапуска.
- Контракт OpenAI-compatible API и ошибочный ответ (MockTransport).
- Ошибка фоновой генерации видна через статус задачи.
- PDF/HTML проверяются, когда LibreOffice установлен; иначе тест явно skipped.

Реальный инференс и нагрузочные испытания требуют выбранной модели/провайдера. `scripts/demo_backend.py` создаёт девять презентаций из одного контента для воспроизводимого демонстрационного прогона.
