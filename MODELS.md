# Модели

## Конфигурация

Модель не зашита в код и не выбрана автоматически. `DESIGNER_LLM_BASE_URL`, `DESIGNER_LLM_MODEL`, `DESIGNER_LLM_API_KEY` задают единственного провайдера для планирования и контекстуального аудита. Никаких скрытых вызовов закрытых моделей Presenton нет.

Подходящий пример: [Qwen3-32B](https://huggingface.co/Qwen/Qwen3-32B), открытые веса, лицензия Apache 2.0. Карточка содержит инструкции запуска OpenAI-совместимого сервера. Область применения здесь — генерация JSON-структуры и анализ текста. Модель не проверяет изображение слайда.

Для финального этапа следует указать выданный VK адрес и фактический model ID. Упомянутое в ТЗ имя «Qwen 3.8 27b» не подменяется предположительным идентификатором. Размер и лицензию развёрнутой модели проверяет оператор: произвольный model ID провайдера невозможно достоверно проверить программно.

## Ресурсы

Бэкенду GPU не нужен при внешнем инференсе. Начальная оценка для контейнера: 2–4 CPU, 2–4 GB RAM; большие шаблоны и параллельный LibreOffice могут требовать больше. Это ориентир, не результат нагрузочного теста.

Для локальной 32B-модели одни веса занимают примерно 64 GB при 16-bit или 16 GB при 4-bit, без KV cache и накладных расходов. Фактические требования зависят от сервера, квантования, длины контекста и параллелизма.

## Воспроизводимость и ограничения

Промпты и хеши сохранены в ресурсах. Temperature 0.2; JSON валидируется. Генерация модели не обещает побитовую воспроизводимость. Для полностью детерминированной проверки верстки передайте сохранённый `outline`.

Живой инференс не проверен без адреса API/ключа. Тесты провайдера используют контролируемые ответы. Обработка изображений VLM и text-to-image не реализованы; до их добавления нельзя заявлять выполнение задания со звездочкой или контекстуальную проверку по картинке.
