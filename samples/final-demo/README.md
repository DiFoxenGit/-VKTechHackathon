# Демонстрационные данные

Все значения синтетические. Динамика: 120 → 300 = +150%; обновлённый файл 120 → 360 = +200%. Сумма исходной выручки — 1200, обновлённой — 1260. Единица: тыс. руб. Региональные значения относятся к отдельному примеру сравнения и не являются разложением временного ряда.

Сценарий: загрузить продажи.csv и контекст.txt, цель «Динамика выручки», единица «тыс. руб.», включить связную историю, лимит 10 слайдов. Переключить варианты, изменить заголовок вводного слайда, сохранить, скачать PPTX и PDF. Затем создать презентацию из продажи-обновлено.csv и показать +200% вместо +150%.
