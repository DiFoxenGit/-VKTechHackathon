# Данные и контракт для второй ступени

**Все наборы синтетические.** Они не описывают результаты внедрения или реальный бизнес.

| Папка | Назначение |
|---|---|
| `contract/` | JSON Schema для Dataset, AnalysisRequest, AnalysisResult и три комплекта для Стёпы |
| `datasets/` | Семь логических наборов, запросы, результаты и независимые контрольные ответы |
| `datasets/mutations/` | Изменённые значения, порядок строк, перестановка категорий и пропуски |

В каждом комплекте `contract/`: CSV + полный `.dataset.json` + `.request.json` + `.result.json`.
Первыми можно подключать `time-series`, `categories`, `shares`. Примеры генерируются реальным модулем,
а не написаны вручную под будущую реализацию. `controls.json` содержит независимые суммы, доли,
медиану, пары X/Y и число строк для сверки.

## Семь наборов

1. `01-sales`: месяц × регион × продажи; CSV, JSON и XLSX одной таблицы. Динамика или сравнение
   регионов задаётся целью/измерением, а `series_dimension=c2` сохраняет регионы отдельными рядами.
2. `02-regions`: категорийное сравнение и длинные названия.
3. `03-channels`: доли полного итога с доказанным знаменателем.
4. `04-orders`: 60 заказов, суммы и длительность; гистограмма либо scatter при явном выборе двух метрик.
5. `05-catalog`: 240 строк, 24 страницы по 10 строк, сумма 28 920. Ни одна строка не обрезана.
6. `06-missing`: пропуск в марте, выброс в июне; пропуск остаётся null, выброс сохраняется.
7. `07-report`: текстовый отчёт со встроенной Markdown-таблицей и окружающим контекстом.

## Воспроизведение

Из корня репозитория, Python 3.11+ с зависимостями бэкенда:

```sh
python tools/make_analytics_samples.py
cd backend
python -m pytest -q tests/test_analytics.py
```

Генерация повторяема (seed 20261017); XLSX использует фиксированные метаданные ZIP и не зависит
от версии zlib. Тест сравнивает сгенерированные артефакты и проверяет независимые контрольные значения.
Готовый экспорт презентации и скринкаст этими файлами не подтверждаются: это задачи интеграции.

Проверка доступных файлов команды и критериев D1–D6: [матрица готовности](../../docs/analytics-acceptance.md),
[машинный отчёт входов](acceptance-inputs.json). Технические таблицы документации не считаются реальными
бизнес-датасетами; рабочих CSV/XLSX вне этих примеров при проверке не найдено.

English: all seven datasets are synthetic. Contract examples include raw CSV, full Dataset,
AnalysisRequest and computed AnalysisResult. The generator is deterministic and separate controls
record expected arithmetic. These fixtures do not claim end-to-end presentation/export verification.
