# Словарь синтетического набора v1

Все деньги — RUB без НДС. Месяц — закрытый календарный YYYY-MM.
CSV с заголовком, UTF-8, запятая-разделитель. Денежные исходные значения в v1 —
целые рубли; контракт принимает также до двух десятичных знаков с точкой.

| Поле | Значение / правило |
|---|---|
| month | Месяц продажи/плана, не дата оплаты и не когорта клиента |
| region_id | Внешний ключ regions.region_id |
| product_id | Внешний ключ products.product_id |
| channel | direct, online, partners; только в факте |
| gross_revenue_rub | Выручка до скидок и возвратов |
| discount_rub | Положительная сумма скидок, вычитается один раз |
| refund_rub | Положительная сумма возвратов, вычитается один раз |
| cogs_rub | Себестоимость после корректировок возврата |
| orders_count | Целые заказы в непересекающихся ячейках; не уникальные клиенты |
| currency | Только RUB; никаких неявных курсов |
| net_revenue_plan_rub | План чистой выручки на месяц–регион–продукт |
| gross_profit_plan_rub | План валовой прибыли на том же зерне |
| option_id | Ключ тарифной опции каталога; не ключ позиции продажи |
| term_months | Срок тарифной опции 1/6/12 месяцев |
| list_price_rub | Синтетическая справочная цена, не фактическая выручка |

Ключ продаж: month+region_id+product_id+channel; ключ плана:
month+region_id+product_id. Справочники имеют уникальные строковые ID.
Номера исходных строк в доказательствах начинаются с 2 после заголовка.

Net = gross − discount − refund; profit = net − cogs; margin = 100×SUM(profit)/SUM(net).
Процентные пункты — разница маржи; growth = 100×(net_current−net_base)/net_base.
Доля возвратов = 100×SUM(refund)/SUM(gross). Нет пропуска как нуля, суммирования
готовых процентов или среднего маржи по строкам. ROUND_HALF_UP до двух знаков
только на отображении; вычисления Decimal с точностью 50.

При нулевом/отрицательном знаменателе отношение null с предупреждением.
Для отрицательных корректировок нет согласованной политики: отдельный отказ.
Все ограничения и границы интеграции: [контракт](../../docs/business-data-contract.md).
