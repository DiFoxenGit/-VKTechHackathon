# Эталонные колоды

Сохранённые ниже файлы относятся к прогону **25 сентября**. После проверки архивов
27.09 изменены планировщик, аудит и материал: сравнение разных временных периодов
больше не используется как доказательство роста. Колоды требуется пересобрать
сценарием 1.12.0; результаты старого прогона не перенесены на новый код.

Актуальный сборщик импортирует файлы из `--template-dir` (или явно указанные
`--template`), включает проверку содержания и скачивает **PPTX, PDF и HTML**.
Полные отчёты и входной материал сохраняются в `evidence/`, сведения о запуске —
в `run.json`. `report.json` отдельно хранит ошибки, предупреждения, хеши экспортов
и время вместе со скачиванием файлов. Режим `--visual-audit` дополнительно включает
проверку по изображению. `--require-chart` отклоняет набор без нативного графика.
Пример нового прогона: `python tools/make_samples.py http://localhost:8000 --template-dir templates --output output/tz-review --require-chart`.

Девять презентаций: три шаблона × три варианта вёрстки. Материал один и тот же —
[source/материал-инициатива.md](source/материал-инициатива.md), бриф один и тот же. Различие в колодах
целиком объясняется шаблоном и вариантом, а не подбором входных данных.

Всё собрано боевым сервисом, а не вручную: `python tools/make_samples.py http://<адрес>`.
Скрипт загружает материал, запускает генерацию, дожидается задачи и скачивает pptx и pdf.

## Как читать предупреждения

Аудит делит находки на ошибки и предупреждения. **Ошибок в наборе нет.**
Предупреждение — это повод посмотреть глазами, а не брак:

| Код | Что значит |
|---|---|
| `fill_ratio` | слайд заполнен меньше, чем мог бы: материала на эту мысль немного |
| `text_over_image` | текст лежит на фоновой картинке шаблона; читаемость обеспечена подложкой и контрастом |
| `text_overflow` | оценка высоты текста близка к границе рамки |
| `branding_overlap` | блок подошёл близко к декоративному элементу шаблона |
| `empty_content` | на слайде только заголовок |
| `word_break` | длинное слово переносится внутри строки |
| `title_topic` | заголовок называет тему или раздел, а не вывод |
| `unverified_number` | число со слайда не найдено в материалах дословно |
| `source_reference` | слайд не сослался на материал |

Каждое предупреждение видно в интерфейсе, у большинства есть автоматическое исправление.

## Файлы

- `<шаблон>__classic.pptx` / `.pdf` — вертикальный рассказ;
- `<шаблон>__split.pptx` / `.pdf` — две колонки;
- `<шаблон>__focus.pptx` / `.pdf` — акцент на одной мысли;
- `report.json` — тот же отчёт в машинном виде.

PPTX открывается и редактируется: текст, таблицы, диаграммы и фигуры — нативные
объекты, ни одного слайда-картинки. Проверку делает `verify_pptx` при каждом
экспорте, её результат лежит в записи презентации (`export_check`).
